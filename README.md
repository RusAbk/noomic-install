# Установщик Нумика

Публичный загрузчик для первой установки и обновления сервера. Исходники приложения и контейнеры остаются закрытыми: нужен аккаунт GitHub с доступом к проекту.

Ubuntu 22.04/24.04/26.04 или Debian 12/13, x86_64. Направьте домены приложения и API на сервер, откройте TCP 80 и 443. Подключитесь по SSH под root и вставьте одну команду:

```bash
bash -c 'set -eo pipefail; apt-get -o DPkg::Lock::Timeout=180 update; apt-get -o DPkg::Lock::Timeout=180 install -y ca-certificates curl; curl -fsSL https://raw.githubusercontent.com/RusAbk/noomic-install/main/install.sh | bash'
```

Загрузчик установит Docker, Compose и остальные зависимости, предложит вход GitHub по коду в браузере, затем спросит домены, email и данные первого администратора. Docker и Node.js заранее устанавливать не требуется.

Повторите ту же команду для обновления. Выбирается последний полностью опубликованный проверенный выпуск; API и веб устанавливаются с одинаковым точным SHA. Настройки и данные сохраняются, ссылка на текущий выпуск меняется после успешного запуска. Перед обновлением приложения создаются резервные копии; база при ошибке автоматически не откатывается.

По умолчанию файлы находятся в `/opt/noomic`, постоянная конфигурация — в `/opt/noomic/deployment/config.env`. `bash install.sh --help` показывает параметры, включая `--yes` для автоматизации и `--release server-<полный SHA>` для выбора выпуска. Токены и пароли передавайте через защищённое окружение, не в аргументах команд.

Изменения загрузчика ведутся в `deployment/bootstrap.sh` основного репозитория. Здесь публикуется проверенная копия без исходников приложения и секретов.
